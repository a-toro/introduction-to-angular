# Configuración de angular
Instalar el CLI.
```shell
npm install -g @angular/cli
```
Confirmar la versión
```shell
ng version
```

Ejecutar el servidor.
ng serve

Clonar repositorio
git clone https://github.com/angular/introduction-to-angular.git
cd introduction-to-angular
git checkout get-started
npm install

levantar el servidor
ng serve
